# Oval Geolocation Microservice

A simple geolocation microservice that converts IPs over to a relative location, useful for routing or basing ips to a location for informative reasons (eg: where a login session was created)

## Attribution

This service internally downloads a database from: https://db-ip.com/
The free IP to City Lite database (the database this service downloads) by DB-IP is licensed under a Creative Commons Attribution 4.0 International License.

In the case of a web application, you must include a link back to DB-IP.com on pages that display or use results from the database. You may do it by pasting the HTML code snippet below into your code:

```html
<a href="https://db-ip.com">IP Geolocation by DB-IP</a>
```
